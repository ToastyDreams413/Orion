Orion

AI-assisted global threat detection and decision support

This deck is written for someone exploring the demo on their own. Use the arrows to step through what the simulator is modeling, what each interface is doing, and how the AI advisor is grounded.

What You Are Looking At

Orion is a browser-based defense simulation that turns moving air/space objects into ranked risk, evidence, and advisory recommendations.

Input

Simulated world state

Objects have positions, altitude, velocity, type, sensor readings, and scenario context such as weather or jamming.

Reasoning

Detection + scoring pipeline

The backend converts raw motion and sensor data into interpretable features, threat scores, classifications, and recommended action categories.

Output

Human-readable decision support

The dashboard shows what matters most, why it matters, and what the advisor recommends checking or doing next.

What the Simulation Tracks

Object-level signals

  • Class/type: aircraft, missile, satellite, debris, asteroid, unknown
  • Kinematics: speed, heading, altitude, acceleration, predicted path
  • Proximity: closest approach, time-to-zone, restricted-area intersection

Context-level signals

  • Sensor confidence, transponder status, thermal/radiation/plume cues
  • Environment: weather, jamming, hazard zones, civilian exposure
  • Behavior patterns: swarm likelihood, anomaly pressure, intent/capability estimates

Where the AI Fits

The advisor is not meant to invent facts. It is given a compact evidence packet from the live scenario and must ground its answer in that packet.

1

Focus selection

It identifies whether the user is asking about a named track, the selected object, or the highest-priority object in the scene.

2

Evidence packet

The backend sends ranked tracks, score components, sensor evidence, confidence, and scenario conditions to the advisor.

3

Constrained answer

The final response returns a recommendation category, confidence, supporting evidence, and the next verification step.
